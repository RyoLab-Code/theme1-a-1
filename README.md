# 【アプリ名】
同志社学内マップ
## 誰の、どんな困りごとか
在学生（特にキャンパスに慣れていない1回生）や仕事などの用事で初めて大学に来た人の、「キャンパスが広く建物も多いため、どこに何があるか分かりにくく、工事中で通れない道もあるので慣れていないと迷ってしまう」という問題

## コア機能1つ
キャンパス内の交通状況、建物の名前などを1画面で確認できる

## 誰が・いくら・なぜ払うか
誰が：大学（利用者である学生・来訪者は無料）
いくら：月10,000円程度（サーバー代と、工事情報などの更新作業を想定）
なぜ：工事・通行止め情報が最新に保たれ、既存のMAPより迷いにくくなることで、学生や来訪者の利便性が上がり、大学の案内対応などの負担も減ると考えられるため。

## 17:15 に見せる操作



画面上に建物の一覧、クリックで設備、詳細が確認でき
